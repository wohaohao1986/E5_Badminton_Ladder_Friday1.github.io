# E5 Badminton Ladder Tool

A Node.js Web application to handle ladder system, dedicately designed for E5 Badminton Club

## Installation

### On Windows: 
1. Download and install Node.js from offical website: https://nodejs.org/en/download

2. Add Node.js root directory to PATH environment variable

3. Open command prompt or Powershell, verify installation
```bash
node -v
```

## Usage
In root directory
```bash
# install required packages
npm install

# run server
node ./src/server.js
```
